S-R Flip-Flop
•This is the simplest flip-flop circuit. It has a set input 
(S) and a reset input (R). 
•In this circuit, when S is set as active, the output Q 
will be high and the Q’ will be low. 
•If R is set to active, then the output Q is low and 
the Q' is high. 
•Once the outputs are established, the results of the 
circuit are maintained until S or R get changed, or 
the power is turned off.

Flip Flop Conversion
•Flip-flop conversion refers to the process of 
modifying one type of flip-flop (e.g., SR, D, JK, or T) 
to behave like another type by designing an 
appropriate input logic circuit. 
•This is often required when a specific flip-flop is not 
directly available or for simplifying circuit design.


===== PAGE 19 =====

•General Steps for Flip-Flop Conversion
•Understand the Source and Target Flip-Flops:
• Identify the type of flip-flop you have (source flip-flop) and 
the type you want to convert it into (target flip-flop).
• Know the characteristic equations and truth tables for both 
types.
•Write the Truth Table for the Target Flip-Flop:
• Create a truth table for the target flip-flop based on its 
characteristic equation and behaviour. Include the current 
state (Q), the input of the target flip-flop, and the next state 
(Qnext).
•Relate the Target and Source Flip-Flops:
• For each possible combination of Q (current state) and 
Qnext (desired next state), determine the required inputs for 
the source flip-flop to achieve the same behaviour.


===== PAGE 20 =====

•Determine the Input Expressions:
• Derive the logic expressions for the inputs of the source 
flip-flop that will allow it to produce the same output 
transitions as the target flip-flop.
• Use Karnaugh maps (K-maps) or Boolean algebra to 
simplify the input logic expressions.
•Design the Conversion Logic Circuit:
• Use the simplified expressions to design a circuit using 
logic gates that connect the input(s) of the source 
flip-flop to behave like the target flip-flop.
•Verify the Conversion:
• Validate the conversion by ensuring that the source 
flip-flop with the designed logic produces the same 
Qnext as the target flip-flop for all input conditions.

shift registers
• A flip-flop is a 1-bit memory cell that can be used for 
storing digital data. To increase the storage capacity 
in terms of the number of bits, a group of flip-flops is 
used. 
•Such a group of flip-flops is known as a Register.
• The n-bit register will consist of n flip-flops, and it is 
capable of storing an n-bit word.
•The binary data in a register can be moved within the 
register from one flip-flop to another. 
•The registers that allow such data transfers are called 
shift registers. There are four modes of operation of 
a shift register.

•Serial In - Serial Out (SISO) Shift Register
•Serial In - Parallel Out (SIPO) Shift Register
•Parallel In - Serial Out (PISO) Shift Register
•Parallel In - Parallel Out (PIPO) Shift Register

Serial In - Parallel Out (SIPO) Shift Register
•In such types of operations, the data is entered serially 
and taken out in a parallel fashion.
•Data is loaded bit by bit. The outputs are disabled as 
long as the data is loading.
•As soon as the data loading gets completed, all the 
flip-flops contain their required data, and the outputs 
are enabled so that all the loaded data is made 
available over all the output lines at the same time.
•4 clock cycles are required to load a four-bit word. 
Hence, the speed of operation of SIPO mode is the 
same as that of SISO mode.

Load Mode
•When the shift/load bar line is low (0), the AND gates 2, 
4, and 6 become active they will pass B1, B2, B3 bits to the 
corresponding flip-flops. 
•On the low-going edge of the clock, the binary inputs B0, 
B1, B2, B3 will get loaded into the corresponding flip-flops. 
Thus, parallel loading takes place.
Shift Mode
•When the shift/load bar line is low (1), the AND gates 2, 
4, and 6 become inactive. Hence, the parallel loading of 
the data becomes impossible.
• But the AND gates 1,3, and 5 become active. Therefore, 
the shifting of data from left to right bit by bit on the 
application of clock pulses. Thus, the parallel in serial out 
operation takes place.

Operation
•Initially, let both the FFs be in the reset state, then 
QBQA = 00 initially.
After 1st negative clock edge
•As soon as the first negative clock edge is applied, FF-A 
will toggle, and QA will be equal to 1.
•QA is connected to the clock input of FF-B. Since QA has 
changed from 0 to 1, it is treated as the positive clock 
edge by FF-B. There is no change in QB because FF-B is 
a negative edge-triggered FF.
•QBQA = 01 after the first clock pulse.


===== PAGE 50 =====

After the 2nd negative clock edge
•On the arrival of the second negative clock edge, 
FF-A toggles again and QA = 0.
•The change in QA acts as a negative clock edge for 
FF-B. So it will also toggle, and QB will be 1.
•QBQA = 10 after the second clock pulse.
After the 3rd negative clock edge
•On the arrival of the 3rd negative clock edge, FF-A 
toggles again, and QA becomes 1 from 0.
•Since this is a positive change, FF-B does not 
respond to it and remains inactive. So QB does not 
change and continues to be equal to 1.
•QBQA = 11 after the third clock pulse.


===== PAGE 51 =====

After the 4th negative clock edge
•On the arrival of the 4th negative clock edge, FF-A 
toggles again, and QA becomes 1 from 0.
•This negative change in QA acts as a clock pulse for 
FF-B. Hence, it toggles to change QB from 1 to 0.
•QBQA = 00 after the fourth clock pulse.

Types of Binary Counters
•Asynchronous Counter − The type of binary counter in 
which the flip-flops do not receive the same clock pulse 
at the same time is called an asynchronous counter. 
•The asynchronous counter is also known as a ripple 
counter. It is the simplest type of binary counter. 
•In the case of an asynchronous binary counter, each 
flip-flop is triggered by the output of the previous 
flip-flop. 
•Therefore, the asynchronous counters suffer from 
propagation delay.


===== PAGE 58 =====

•Synchronous Counter − The type of binary counter in 
which all the flip-flops receive the same clock pulse at 
the same time is known as a synchronous counter.
• Since the same clock pulse triggers all the flip-flops of 
the synchronous counter, their outputs change 
simultaneously. 
•This will result in no propagation delay between the 
flip-flops.
•Up Counter − The type of binary counter that counts 
upwards from zero to its maximum count value is 
known as an up counter. 
•In the case of an up counter, the count is increased by 
one on each clock pulse.


===== PAGE 59 =====

•Down Counter − The type of binary counter that 
counts downwards from its maximum count value 
to zero is known as a down counter. In the down 
counter, the count value of the counter is 
decreased by one on each clock pulse.
•Up/Down Counter − The type of binary counter 
that can count in both upward and downward 
directions is known as an up/down counter. In the 
up/down counter, the direction of count is 
determined by a control input signal.

4-bit binary Adder-Subtractor
• A Binary Adder-Subtractor is can do both the addition 
and subtraction of binary numbers in one circuit itself. 
The operation is performed depending on the binary 
value the control signal holds. It is one of the components 
of the ALU (Arithmetic Logic Unit). 
What is a Binary Adder?
• A Binary Adder is an electronic circuit that sums two 
binary numbers. The most basic types are half adders and 
full adders. A half adder takes in two one-bit numbers, 
producing a sum and a carry bit. 
• Full adder has three input bits: two actual bits and an 
incoming carry from the preceding operation. This makes 
the Full Adder to add multi-bit binary numbers as the 
carry can propagate through several Full Adders in a 
ripple-carry adder configuration.


===== PAGE 61 =====

What is Binary Subtractor?
•A Binary Subtractor is used to perform the subtraction of 
two binary numbers. Just as with addition, this can also 
be done using an array of logic gates. 
•The subtraction is done by using two's complement, in 
which the circuit first negates the binary number to 
obtain its complement and then adds one to the result 
before inputting it into a binary adder circuit together 
with the original number. 
•Both addition and subtraction are handled by this type of 
circuit.
•The circuit consists of 4 full adders since we are 
performing operations on 4-bit numbers. 
•There is a control line K that holds a binary value of 
either 0 or 1, which determines whether the operation is 
carried out is addition or subtraction.

Types of ROM
•The programmable ROM (PROM) is used when a 
few ROMs are required with a specific memory 
content. PROMs can be written only once using 
electric signals.
•The erasable programmable ROM (EPROM) can be 
read and written using electrical signals.
• Before a write operation is performed, the 
memory content of this memory chip is erased to 
retain its initial state by exposing the memory chip 
to the ultraviolet rays.
•The EPROM can be erased and updated repeatedly, 
and like ROM and PROM, it retains its memory 
content even if there is no power supply. 
Compared to ROM and PROM the EPROM is more 
expensive.


===== PAGE 77 =====

•The electrically 
erasable 
programmable 
ROM (EEPROM) is the ROM memory that can be

• Unlike the EPROM, where the entire data gets 
erased when exposed to the ultraviolet rays, in 
EEPROM, the selective data can be erased without 
removing the memory chip from the system, as 
with a higher-than-normal electrical voltage, the 
data can be erased. 
•The EEPROM is a little complex when compared to 
the EPROM, as it requires a different electrical
