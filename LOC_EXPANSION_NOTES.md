# LOC Expansion Notes

This update adds `curriculum_catalogs/`, a collection of importable Python modules
containing structured engineering exercises across analog circuits, converters,
timers, digital logic, instrumentation, signals, semiconductors, and embedded systems.

Each catalog record has a unique identifier, a topic, an applied engineering prompt,
a skill tag, and a difficulty level. These are curriculum data and should be treated
as additional maintained source, not as a claim that each line represents a separate
application feature. Run the repository's own LOC checker to confirm its counting policy.
